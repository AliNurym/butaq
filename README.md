## 💡 Манифест проекта (Architectural Pitch)

Программирование не должно зависеть от знания английского языка. Человеческий язык в исходном коде — это всего лишь **сменяемая синтаксическая проекция («шкурка»)**. Внутри компилятора работает единое строгое инженерное ядро: не зависящее от языка абстрактное синтаксическое дерево (Unified AST), статический типизатор с семантическим анализом и генератор нативного машинного кода через LLVM с оптимизациями `-O3` без единой доли потери производительности.

### 🌳 Смысл названия Butaq («Бұтақ» — Ветка)
Компилятор устроен по принципу живого дерева:
- **Единый ствол (Compiler Trunk):** лексический абстрактор, типизатор, сборщик мусора на основе ARC (Automatic Reference Counting), оптимизатор и генератор машинного кода LLVM IR.
- **Ветви синтаксиса (Syntax Branches / Бұтақтар):** национальные языковые проекции (казахская ветвь, английская ветвь, итальянская ветвь, русская ветвь и любая другая ветвь, добавляемая через простой конфигурационный файл).

## 🏗️ Архитектура компилятора (Pipeline Architecture)

Конвейер компиляции полностью отделяет синтаксический фасад от семантического ядра:

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    Исходный код / Source Code (.btq)                    │
│      [KK] Қазақша   │   [EN] English   │   [IT] Italiano   │   [RU]     │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │
                                     ▼
               ┌──────────────────────────────────────────┐
               │      Locale-Aware Lexer (locales/)       │ ◄── JSON-словари
               └─────────────────────┬────────────────────┘
                                     │
                                     ▼
               ┌──────────────────────────────────────────┐
               │    Единое языконезависимое ядро (AST)    │ ◄── AST Transpiler
               └─────────────────────┬────────────────────┘     (butaq transpile)
                                     │
                                     ▼
               ┌──────────────────────────────────────────┐
               │      Typechecker & ARC Memory Model      │
               └─────────────────────┬────────────────────┘
                                     │
                                     ▼
               ┌──────────────────────────────────────────┐
               │          LLVM IR Code Generator          │
               └─────────────────────┬────────────────────┘
                                     │
                                     ▼
               ┌──────────────────────────────────────────┐
               │    Нативный бинарник (x86-64 Machine)    │
               │         Zero Runtime Overhead            │
               └──────────────────────────────────────────┘
```

## ⚡ Киллер-фича: AST-транспилятор (Bi-directional Transpiler)

Так как компилятор строит **единое каноническое абстрактное синтаксическое дерево (AST)**, код на одном национальном языке можно мгновенно и без потерь транслировать в любой другой поддерживаемый язык:

```bash
# Транспиляция алгоритма с казахского на итальянский:
butaq transpile examples/fib_kk.btq --target=it -o examples/fib_it.btq

# Транспиляция с английского на русский:
butaq transpile examples/fib_en.btq --target=ru

# Транспиляция с итальянского на английский:
butaq transpile examples/fib_it.btq --target=en
```

Это наглядно доказывает, что код логически идентичен, а компилятор не имеет жесткой привязки к конкретному этносу или словарю.

## 🌐 Полиглот-демонстрация: Алгоритм Фибоначчи

Один и тот же алгоритм компилируется в идентичный нативный машинный код на 4 языках:

### 1. 🇰🇿 Казахский синтаксис (`examples/fib_kk.btq`)
```butaq
функция фиб(n)
    егер n <= 1 сонда қайтару n
    қайтару фиб(n - 1) + фиб(n - 2)

жазу("=== Фибоначчи қатары ===")

болсын i = 0
әзірше i <= 10
    жазу("fib(", i, ") = ", фиб(i))
    i = i + 1
```

### 2. 🇬🇧 Английский синтаксис (`examples/fib_en.btq`)
```butaq
func fib(n)
    if n <= 1 then return n
    return fib(n - 1) + fib(n - 2)

print("=== Fibonacci Series ===")

let i = 0
while i <= 10
    print("fib(", i, ") = ", fib(i))
    i = i + 1
```

### 3. 🇮🇹 Итальянский синтаксис (`examples/fib_it.btq`) — *Тактический козырь для Fibonacci Congress в Риме*
```butaq
funzione fib(n)
    se n <= 1 allora ritorna n
    ritorna fib(n - 1) + fib(n - 2)

stampa("=== Serie di Fibonacci ===")

sia i = 0
mentre i <= 10
    stampa("fib(", i, ") = ", fib(i))
    i = i + 1
```

### 4. 🇷🇺 Русский синтаксис (`examples/fib_ru.btq`)
```butaq
функция фиб(n)
    если n <= 1 тогда вернуть n
    вернуть фиб(n - 1) + фиб(n - 2)

печать("=== Ряд Фибоначчи ===")

пусть i = 0
пока i <= 10
    печать("fib(", i, ") = ", фиб(i))
    i = i + 1
```

Все 4 версии компилируются и исполняются с побитово эквивалентным результатом:
```
fib(0) = 0
fib(1) = 1
...
fib(10) = 55
```

## 🚀 Как добавить новый язык за 5 минут (Zero-Cost Extensibility)

Никаких изменений в коде лексера или парсера. Достаточно создать JSON-файл в папке `locales/`:

```json
// locales/es.json (Испанский язык)
{
  "code": "es",
  "name": "Español",
  "keywords": {
    "sea": "VAR",
    "si": "IF",
    "sino": "ELSE",
    "mientras": "WHILE",
    "romper": "BREAK",
    "continuar": "CONTINUE",
    "imprimir": "PRINT",
    "mas": "PLUS",
    "menos": "MINUS",
    "por": "MUL",
    "entre": "DIV",
    "funcion": "FUNC",
    "retornar": "RETURN"
  }
}
```

Компилятор автоматически обнаруживает локаль при запуске и позволяет сразу компилировать код на испанском языке, а также делать двустороннюю транспиляцию.

## 💻 Интерфейс командной строки (CLI)

```bash
# Компиляция в нативный бинарник через LLVM:
butaq build program.btq -o myprog

# Быстрая сборка и запуск программы:
butaq run program.btq

# Транспиляция кода между языками:
butaq transpile program.btq --target=en -o program_en.btq

# Список зарегистрированных локалей:
butaq locales

# Форматирование исходного кода:
butaq fmt program.btq

# Запуск LSP сервера (для VS Code / Neovim):
butaq lsp
```

## 🌐 Интерактивная веб-песочница (Web Playground)

В папке `playground/` доступна среда запуска Butaq в браузере, скомпилированная в **WebAssembly (WASM)**:
- Выпадающий список языков: **KZ (Қазақша) | EN (English) | IT (Italiano) | RU (Русский)**.
- Кнопка **«🔄 Транспиляция (AST)»** — трансформирует текст в редакторе в выбранный язык в реальном времени.
- Кнопка **«▶ Іске қосу»** — запускает код прямо в WebAssembly с отображением вывода в консоль.
- Инспекторы сгенерированного промежуточного кода **LLVM IR** и ассемблера **NASM**.

Запуск локального сервера веб-песочницы:
```bash
cd playground
python -m http.server 8080
# Откройте в браузере: http://localhost:8080
```
