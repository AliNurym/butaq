## 3. Слайдқа арналған 3 басты тезис (Key Presentation Bullet Points)

1. **Таза машина коды (Zero-Cost Abstraction)**:
   - Butaq виртуалды машинасыз және интерпретаторсыз x86-64 машина кодына компиляцияланады.
   - Процессордың аппараттық регистрлерін (`xmm0`, `xmm1`, `rax`, `rcx`) толық қуатында қолданады.

2. **Объектілерді қаптаусыз жады (No Heap Boxing & No GC Pauses)**:
   - Python-да әрбір сан жаңа `PyFloatObject`/`PyLongObject` ретінде кучада (heap) жасалып, миллиондаған рет жады бөледі.
   - Butaq-та бүкіл есептеу тікелей L1 кэш пен аппараттық регистрлерде 0 байт жады шығынымен орындалады.

3. **Синтаксистік локализация өнімділікке әсер етпейді**:
   - Қазақ, ағылшын, итальян немесе орыс тілінде жазылған синтаксис AST деңгейінде нөлдік шығынмен жойылып, бірыңғай супер-жылдам машиналық кодқа айналады.

## 4. Слайдқа арналған мысал коды (Prime Counting)

### Butaq (.btq) — 0.31 секунд:
```butaq
функция жай_сандар_саны(n)
    болсын count = 0
    болсын i = 2
    әзірше i <= n
        болсын is_prime = 1
        болсын d = 2
        әзірше d * d <= i
            болсын q = бүтін(i / d)
            егер i - q * d == 0
                is_prime = 0
                үзу
            d = d + 1
        егер is_prime == 1
            count = count + 1
        i = i + 1
    қайтару count
```

### Python (.py) — 8.62 секунд:
```python
def count_primes(n):
    count = 0
    i = 2
    while i <= n:
        is_prime = 1
        d = 2
        while d * d <= i:
            if i % d == 0:
                is_prime = 0
                break
            d += 1
        if is_prime == 1:
            count += 1
        i += 1
    return count
```
